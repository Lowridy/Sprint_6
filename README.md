# Sprint_6
Репозиторий содержит автоматизированные тесты на Selenium + Pytest + Allure для проверки функциональности сайта копания «Самокат» (https://qa-scooter.praktikum-services.ru).
Тестовые сценарии включают:

Проверку FAQ с автоскроллом и верификацией содержимого.

Позитивный флоу заказа самоката: выбор даты, срок аренды, цвет, комментарий, подтверждение и проверка редиректов по логотипам (Самокат, Яндекс).
